# Retail Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end analytics pipeline using:

- PostgreSQL
- Python
- Pandas
- Plotly
- Dash

The dashboard connects directly to a PostgreSQL database and provides interactive business insights from the Superstore dataset.

## Features

### KPI Cards
- Total Sales
- Total Profit

### Interactive Filter
- Category Dropdown

### Visualizations
- Sales by Sub-Category
- Profit by Region

### Database Integration
- PostgreSQL database connection
- Live queries using SQLAlchemy

## Business Insights

The dashboard allows users to:

- Compare sales performance by category
- Analyze profit distribution by region
- Filter results dynamically

## How to Run

Install dependencies:

```bash
pip install dash dash-bootstrap-components pandas plotly sqlalchemy psycopg2-binary
```

Run:

```bash
python app.py
```

Open:

```
http://127.0.0.1:8050
```
